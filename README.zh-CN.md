# 后印象派编辑双联画技能

[English README](README.md)

## 技能介绍

`post-impressionist-editorial-diptych` 是一个用于 ChatGPT/Codex 的图片生成技能。它会把一张上传照片处理成干净的上下构图编辑图。

上半部分固定保留原始照片，不重绘、不滤镜化、不调色、不抽象化。下半部分会根据原图中的主体、空间关系、色彩、光线和构图轴线，生成一张稀疏的抽象记忆面板，并带有油画质感：可见笔触、轻微厚涂、颜料边缘和破碎色彩。最终图像只包含一个英文诗性标题，且标题只出现在下半部分。

这个技能适合制作安静、克制、带编辑感的照片再创作：上面是真实照片，下面是从照片中提炼出的抽象记忆。

## 功能特点

- 上半部分保留原始上传照片，禁止重绘、滤镜、修图、扩图、风格化或增删对象。
- 下半部分根据照片事实生成抽象面板，例如主体位置、横线、斜线、建筑、树影、月亮、灯光、山水、船只、人物尺度等。
- 下方抽象面板带有油画质感，但仍保持留白、克制和编辑感。
- 自动添加一个 2-5 个词的英文标题，标题必须来自照片可见事实。
- 强制生成上下分区的竖版双联画，而不是整张图都变成绘画。

## 输出风格

生成结果应包含：

- 上半区：原始照片本身，保持摄影感和原始构图。
- 下半区：象牙白背景、稀疏抽象油画笔触、60%-80% 留白。
- 标题：一个英文标题，只放在下半区。
- 不出现边框、Logo、水印、签名、日期、副标题或额外标签。

## 安装方法

### 方法一：通过 ChatGPT Skills 页面安装

如果你的 ChatGPT 或 Codex 环境支持从 GitHub 仓库导入技能：

1. 打开 Skills 页面。
2. 选择添加或导入技能。
3. 输入这个仓库地址：

   ```text
   https://github.com/er7635888/post-impressionist-editorial-diptych
   ```

4. 确认系统能识别仓库根目录下的 `SKILL.md`。
5. 安装或启用该技能。

### 方法二：下载文件夹后安装

1. 下载本仓库 ZIP，或使用 Git 克隆：

   ```bash
   git clone https://github.com/er7635888/post-impressionist-editorial-diptych.git
   ```

2. 保持文件结构不变，确保 `SKILL.md` 位于文件夹根目录。
3. 在你的技能管理器中导入或上传整个文件夹。
4. 如果安装后没有立刻显示，可以刷新 Skills 页面。

### 方法三：放入本地技能目录

如果你的 Codex 类环境支持从本地文件夹加载技能，可以把整个仓库文件夹放入你的个人技能目录，再刷新或重新加载技能发现。具体路径以你的运行环境说明为准。

## 使用方法

可以直接点名调用：

```text
使用 post-impressionist-editorial-diptych 处理这张照片。
```

也可以不输入技能名称，用自然语言触发：

```text
把这张照片做成上下构图：上面保留原图，下面做油画质感的抽象记忆面板，加一个英文标题。
```

更短的说法也可以：

```text
按上原图、下油画抽象面板的样式处理这张图。
```

## 示例提示词

```text
把这张上传图片转成竖版编辑双联画。上半部分保留原始照片；下半部分根据照片里的主体、色彩、光线和构图线条，生成克制的油画质感抽象记忆面板，并添加一个英文诗性标题。
```

## 使用注意

- 上半部分必须保持原图摄影感，不能变成绘画。
- 下半部分应该是抽象面板，不是原图的缩小版插画。
- 油画质感应主要出现在下方面板的抽象笔触里，不应扩散到上半原图。
- 如果生成结果把上半图也画成油画，或下半图过于写实，可以要求重新生成并强调“上半保持原图，下半才是油画抽象”。
